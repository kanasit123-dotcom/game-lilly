# โลกของลิลลี่: แบบร่างสำหรับพัฒนารอบถัดไป

วันที่ 15 กันยายน 2026

## เปิดดู

เปิด `design/index.html` ด้วยเบราว์เซอร์ได้โดยตรง ไม่ต้องติดตั้งหรือรันเซิร์ฟเวอร์

นี่คือ interactive prototype สำหรับดูหน้าตาและทดลองวงจรการเรียน ยังไม่ใช่การเปลี่ยนเกมหลัก 92 ด่าน หน้าเดิมและ service worker เดิมไม่ได้เชื่อมแบบร่างนี้ การบันทึกใช้คีย์ `lilly-design-preview-v1` แยกต่างหาก และไม่สะสมคะแนนเข้าตัวเกมหลัก

ลองได้จริง:

- หน้าแรก: เลือกเพื่อนแมวน้ำ เต่า หรือกระต่าย และเลือกบทเรียน
- ครอบครัว: ผังปู่ ย่า ตา ยาย พ่อ แม่ เรา; แตะคำเพื่ออ่านและฟัง; แบบฝึก 3 ข้อ
- ภาษาไทย: สระอาและคำ กา ตา มา; แบบฝึก 3 ข้อ
- คณิตศาสตร์: รวมแครอตสองกลุ่ม; บวกจำนวนไม่เกิน 5 จำนวน 3 ข้อ
- ภาษาอังกฤษ: Seal, Turtle, Rabbit; เกมความจำภาพกับคำ 3 คู่
- พักเล่น: เก็บแครอต 5 หัวแล้วจบ ไม่มีเริ่มรอบใหม่อัตโนมัติ
- จบรอบ: ไปบทเรียนถัดไป หรือจบการเรียนวันนี้
- สมุดสะสมและหน้าผู้ปกครอง: แสดงบทเรียนที่ทำครบจากการทดลองจริง เปิด/ปิดเสียงได้

เสียงใช้ SpeechSynthesis ของเบราว์เซอร์ คุณภาพและเสียงไทยขึ้นกับอุปกรณ์ ไม่ใช่ไฟล์เสียงที่ตรวจฟังแล้ว ภาพและไอคอนอยู่ในโปรเจกต์ ฟอนต์จาก Google Fonts มี Tahoma/sans-serif สำรอง

## ทิศทางภาพ

ใช้ภาพวาดหนังสือเด็ก เส้นนุ่ม เห็นหน้าตาเต็มชัดเจน พื้นที่โล่ง ตัวอักษรไทยอ่านง่าย สีเขียวใบไม้ ชมพูปะการัง เหลือง และฟ้า ใช้สีเพื่อแยกเนื้อหา ปุ่มเด็กสูงอย่างน้อย 48px และรองรับการลดการเคลื่อนไหวตามระบบ

ตัวละครหลัก: แมวน้ำ เต่า กระต่าย สัตว์อื่นและแมลงเพิ่มภายหลังได้ ไม่เพิ่มหมี หมู ฮิปโป หรือหมาในงานชุดใหม่ตามความชอบที่ผู้ปกครองแจ้ง การตรวจและเปลี่ยนภาพเหล่านี้ในเกมเดิมเป็นงานแยกก่อนนำแบบใหม่ขึ้นจริง

ภาพต้นแบบใช้ไฟล์ร่วมกับเกมจริงที่ `../assets/lilly-friends.png` เป็นภาพเดียว 3 ช่อง ใช้ CSS แสดงแต่ละตัว ในงานจริงควรแยก asset ตามชนิดและท่าทาง พร้อมขนาดมือถือและ alt text: idle, happy, thinking, gentle-encouragement อย่าแสดงหน้าผิดหวังเมื่อเด็กตอบผิด

ภาพสร้างด้วย built-in imagegen; prompt ฉบับเต็มอยู่ใน `ART-PROMPT.md` ไอคอน Lucide 0.468.0 เก็บใน vendor พร้อมใบอนุญาต

## วงจรการเรียน

เลือกบทเรียน → สอนเรื่องเดียวพร้อมภาพ/เสียง → ลองทำ 3–5 ข้อ → สรุปสิ่งที่ทำได้ → มินิเกม 1 ภารกิจ → เลือกเรียนต่อหรือพัก

ข้อเสนอสำหรับทดสอบกับลิลลี่ ไม่ใช่เวลาหรือจำนวนข้อที่หลักสูตรบังคับ:

- หนึ่งบทใช้ประมาณ 3–6 นาที ปรับตามเด็ก ไม่บังคับจับเวลา
- ตอบผิดให้ลองใหม่ มีตัวช่วยภาพและเสียง ไม่หักดาวหรือขึ้นข้อความตำหนิ
- เก็บทั้งจำนวนครั้งที่ลองและคำตอบครั้งแรก เพื่อให้ผู้ปกครองเห็นเรื่องที่ควรทบทวน โดยไม่โชว์อันดับให้เด็ก
- ได้สติกเกอร์เมื่อทำบทเรียนครบ ไม่ต้องตอบถูกครั้งแรกทุกข้อ
- มินิเกมเป็นช่วงพักที่ข้ามได้ จบแล้วไม่เล่นวนและไม่ใช้รางวัลสุ่ม
- มีปุ่มจบวันนี้ที่เข้าถึงง่าย ไม่ใช้ streak หรือข้อความกดดันให้กลับมา

## โครงสร้างเนื้อหา

จัดตามทักษะและความพร้อม ไม่ผูกกับชั้นเรียนอย่างตายตัว และควรเทียบแบบเรียนของโรงเรียนลิลลี่ก่อนลงเนื้อหาชุดใหญ่

| หมวด | ชุดเริ่มต้น อ.2 โดยประมาณ | ขยายความพร้อม อ.3 โดยประมาณ |
| --- | --- | --- |
| ครอบครัว | พ่อ แม่ พี่ น้อง; ปู่ ย่า ตา ยาย | ลุง ป้า น้า อา; อ่านผังสองฝั่ง; คำอังกฤษ |
| ภาษาไทย | ฟังและแยกเสียง; รูปร่างพยัญชนะ; สระง่าย; คำสั้น | ประสมคำ; ตัวสะกดง่าย; แยกพยัญชนะ สระ ตัวสะกด |
| ภาษาอังกฤษ | ฟังแล้วชี้ภาพ; สี ของใช้ สัตว์ ร่างกาย; เสียงต้นคำ | ภาพกับคำ; อักษรใหญ่/เล็ก; วลีและคำสั่งสั้น |
| คณิตศาสตร์ | จับคู่หนึ่งต่อหนึ่ง; จำนวน 1–10; มาก/น้อย; รูปทรง; แบบรูป | จำนวนถึง 20 ตามความพร้อม; รวม/เอาออก; โจทย์ภาพ; หลักสิบ/หน่วย |
| โลกใกล้ตัว | อารมณ์ กิจวัตร สุขนิสัย ฤดูกาล | เรียงเหตุการณ์ แยกหมวด สิ่งมีชีวิต สังเกตและคาดคะเน |

การตั้งบวก/ตั้งลบควรอยู่ชุดเสริมหลังเข้าใจปริมาณ การรวม/เอาออก และหลักสิบ/หลักหน่วย เริ่มไม่ทดไม่ยืม ส่วนทด/ยืมเพิ่มตามความพร้อม ไม่ใช้เป็นเกณฑ์หลักสำหรับเด็กอนุบาลทุกคน

แหล่งอ้างอิงสำหรับกรอบออกแบบที่ได้สำรวจในงานก่อนหน้า:

- [สพฐ. หลักสูตรการศึกษาปฐมวัย 2560](https://academic.obec.go.th/images/document/1590998426_d_1.pdf): ใช้เป็นกรอบพัฒนาการและประสบการณ์เด็ก ไม่อ้างว่าเป็นหลักสูตรล่าสุดหรือแผนโรงเรียนของลิลลี่
- [สสวท. กรอบวิทยาศาสตร์ เทคโนโลยี และคณิตศาสตร์ปฐมวัย](https://www.scimath.org/ebook-science/item/11322-2020-03-05-01-33-35): ใช้สนับสนุนกิจกรรมสังเกต เปรียบเทียบ และคณิตศาสตร์จากสิ่งใกล้ตัว

### จุดที่ต้องตรวจเนื้อหา

- ปู่ = พ่อของพ่อ, ย่า = แม่ของพ่อ, ตา = พ่อของแม่, ยาย = แม่ของแม่
- ในชุดเครือญาติสายตรง ลุง/ป้าคือพี่ชาย/พี่สาวของพ่อหรือแม่; น้าคือน้องของแม่; อาคือน้องของพ่อ ญาติเกี่ยวดองเพิ่มเป็นอีกบทเพื่อไม่ทำให้กติกาชุดแรกสับสน
- Uncle/Aunt ไม่แยกน้า/อาหรืออายุแบบไทย; Grandfather/Grandmother ไม่แยกฝั่งพ่อ/แม่ จึงห้ามสร้างโจทย์แปลกลับที่มีคำตอบไทยถูกหลายตัวเลือกโดยไม่ได้ให้บริบท
- ครอบครัวในบทเป็นตัวอย่าง ไม่สมมติว่าเด็กทุกคนอาศัยกับพ่อแม่ครบทั้งสองคน
- เสียงชื่อพยัญชนะกับเสียงที่ใช้ประสมคำต้องแยกชัด; มีรายการเสียงผ่านการตรวจฟังจริงก่อนปล่อย

## แนวทางเชื่อมโค้ดเดิม

- เพิ่มตัวแสดงภาพกลางที่รับ asset ID, alt, spokenText, language และคง fallback สำหรับด่านเก่า
- ใช้ WORD_SETS และ config เดิมต่อ ขยายเฉพาะฟิลด์ที่จำเป็น ไม่เขียนเกมทุกด่านใหม่
- แยกเนื้อหาจาก engine; ชุดใหม่ต้องมี unique level ID และไม่เปลี่ยน ID 92 ด่านเดิม
- บทเรียนสั้นมี lifecycle เช่นเดียวกับเกม: mount และ cleanup
- เพิ่ม onComplete/onExit ให้ minigame host ส่งกลับบทเรียนต้นทางได้ และยกเลิก timeout/audio/listener เมื่อออก
- ใช้ state เดิมและ migration เฉพาะเมื่อ schema เปลี่ยน; ห้ามล้างความคืบหน้าเพื่อเริ่มธีมใหม่
- ก่อนขึ้นจริง เพิ่มไฟล์ใหม่ใน sw.js, เปลี่ยน cache version, ตรวจ refresh และ offline, ตรวจ git diff แล้วจึง commit/push ตามขั้นตอนเผยแพร่ที่ตกลงกัน

## แผนใช้โมเดลให้คุ้ม

ข้อแนะนำสำหรับงานนี้ ไม่ใช่การรับรองค่าใช้จ่ายหรือจำนวน token:

| งาน | โมเดล/ความละเอียดที่แนะนำ |
| --- | --- |
| ตกลงระบบภาพ, session flow, การย้ายคะแนน, ตรวจงานก่อนรวม | GPT-6 Astra High |
| ทำหน้าจอ/แก้เกมทีละไฟล์ตามแบบที่ชัด | GPT-5.6 Terra Medium; เพิ่ม High เมื่อมีหลายสถานะหรือบั๊กยาก |
| เพิ่มชุดคำและด่านตาม schema ที่ผ่านตรวจแล้ว | GPT-5.6 Luna Medium; ตรวจความถูกต้องของเนื้อหาก่อนรวม |
| ผลิตภาพ | imagegen แยกจากโมเดลเขียนโค้ด; อนุมัติสไตล์ตัวอย่างก่อนทำจำนวนมาก |

โมเดลเล็กอาจใช้ token จำนวนใกล้เคียงแต่ต้นทุนต่ำกว่า และบางงานต้องแก้หลายรอบจนไม่คุ้ม วิธีประหยัดคือส่งงานชัด ๆ พร้อมขอบเขตไฟล์ ตัวอย่างข้อมูล และเงื่อนไขเสร็จ หลีกเลี่ยงให้แต่ละรอบอ่านทั้งโปรเจกต์ซ้ำ และตรวจตอนจบแต่ละชุด

อ้างอิง [OpenAI Docs: Models](https://learn.chatgpt.com/docs/models): Terra สำหรับงานทั่วไป, Luna สำหรับงานชัดเจนทำซ้ำได้ และเลือก reasoning ต่ำที่สุดที่ทำงานผ่าน งานออกแบบรอบนี้ยังใช้โมเดลปัจจุบัน ไม่มีการเปลี่ยนโมเดลหลักหรือเปิดผู้ช่วยโมเดลอื่นอัตโนมัติ

## การตรวจแบบร่าง

ใช้ `node design/verify.cjs` เมื่อมีแพ็กเกจ Playwright และติดตั้ง Chrome แล้ว สคริปต์เปิดไฟล์ใน browser context ชั่วคราว ไม่ใช่โปรไฟล์ Chrome ของผู้ใช้ ภาพตรวจอยู่ใน `review/`

ตรวจวงจรครบ 4 บท, ตอบผิดแล้วลองใหม่, จับคู่ถูก/ผิด, มินิเกมจบหลัง 5 หัว, การคงสติกเกอร์และตัวละครหลัง reload, ปิดเสียง, ไม่เปลี่ยนคีย์บันทึกอื่น และหน้าจอขนาด 320/390/768/1280px ตรวจภาพหน้าหลัก ผังครอบครัว และสวนแครอตด้วยสายตาประกอบ

ยังไม่ได้ตรวจฟังเสียงจริงบน iPad/Android และยังไม่ได้เชื่อม/ทดสอบกับ service worker ของเกมหลัก
